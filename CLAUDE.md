## Working rules
- **No Swift toolchain on this machine.** GitHub Actions (macOS) compiles and tests. Push early, read CI failures, fix. Put logic in `Packages/*` so `swift test` proves it.
- Work through `.claude/skills/sequential-issues` items. Read only the files an item names, then what they import; never survey the Android/web repos.
- Wire types come from the backend C# contracts, not the TS.
- `.xcodeproj` is generated by XcodeGen from `project.yml`; never hand-edit it.
- No attribution trailers on commits or PRs.
- Held for the user: design decisions, anything needing a device or a visual judgement.
